# จัดคนเข้าทีม · หน่วยที่ 5 (Vite + React + glisse)

## ขึ้น Netlify
1. อัปโค้ดนี้ขึ้น GitHub แล้ว "Add new site → Import from Git" (หรือ `npm i -g netlify-cli && netlify deploy --prod`)
2. Build command: `npm run build` · Publish directory: `dist` (ตั้งไว้ใน netlify.toml แล้ว)

## รันในเครื่อง
npm install
npm run dev
